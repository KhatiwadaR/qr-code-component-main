# QR Code Component

A simple and responsive QR code component built as part of the Frontend Mentor challenge.  
This project focuses on building a clean UI using HTML and CSS and improving layout and styling skills.

- Clean and minimal UI design

- Centered QR card design
- Pixel-perfect layout based on challenge design
- Beginner-friendly HTML & CSS structure
